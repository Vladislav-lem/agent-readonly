Privacy policy

Applies to the app “WAW agent readonly”. Last updated: 24 November 2026.

Who uses it

The app is a personal tool used only by its owner, with the owner's own Google account. It is not distributed to other users.

What data it accesses

With the owner's consent, the app requests read-only access to Gmail, Google Calendar and Google Drive. It cannot send, change or delete anything.

How data is used and stored

  • Data is read on the owner's own computer, only when the owner asks the assistant a question.
  • The app has no servers. It does not collect, store, sell or share data with third parties, and does not use it for advertising.
  • The access token is kept only on the owner's computer.

Google API data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
